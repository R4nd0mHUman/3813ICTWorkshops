# Hello World - Week 2 Task 1

## Project Description

This project is a simple JavaScript program that prints **"Hello World!"** to the console. It is designed to practice using GitHub with the favoured coding terminal. The project also demonstrates how to navigate between directories using the command prompt.

---

## Installation Instructions

1. Install **Node.js** from https://nodejs.org/en/download.
2. Install **Visual Studio Code** from https://code.visualstudio.com/download?_exp_download=d53503e735.
3. Open the project folder in Visual Studio Code.
4. Open the integrated terminal.
5. Ensure the terminal is using **Command Prompt (cmd)** instead of PowerShell by right-clicking the **+** icon and selecting **Command Prompt**.

---

## Run Instructions

1. Open the terminal in Visual Studio Code.
2. Navigate to the project folder:

   ```cmd
   cd "Task 1"
   ```

3. Run the JavaScript file:

   ```cmd
   node index.js
   ```

4. The terminal should display:

   ```
   Hello World!
   ```

5. To return to the parent directory:

   ```cmd
   cd ..
   ```
